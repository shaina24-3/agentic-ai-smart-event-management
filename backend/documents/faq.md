# Frequently Asked Questions (FAQ)

## General Event Inquiries
Q: How can I interact with the AI Event Assistant?
A: You can talk to the Smart Event Assistant via natural language chat. You can say greetings like "Hi", "Hello", ask "What venues are available?", "Find AI workshops", or instruct it to "Create an event" and "Book venue".

Q: Who is authorized to create or cancel events?
A: Users with ADMIN role or assigned Event Organizers have permissions to create, update, or cancel scheduled events. Standard participants can browse events, check venue details, register, and cancel their personal registrations.

Q: How do I know if a venue has available seats?
A: The assistant checks real-time database capacity against registered attendees. If seats remain, you can register instantly. Once maximum capacity is met, the event status changes to FULL.

Q: What happens if I try to book a venue that is already booked?
A: The system checks for scheduling conflicts on the requested date. If occupied, the assistant alerts you that the venue is unavailable and suggests alternate dates or open venues.
